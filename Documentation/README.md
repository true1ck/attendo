# 📚 ATTENDO Documentation Hub

Welcome to the complete documentation suite for the ATTENDO Vendor Timesheet Management System!

## 🎯 Overview

This Documentation folder contains all user guides, system documentation, and technical references for ATTENDO. The documentation is completely **portable** and uses relative paths, so you can move this folder anywhere and it will continue to work.

## 📁 Files Included

### 📋 Core Documentation Files

1. **`index.html`** - 🏠 **Main Documentation Hub**
   - Beautiful landing page with all documentation links
   - Quick start guide for different user roles
   - Responsive design with animations

2. **`vendor_documentation.html`** - 👤 **Vendor User Guide**
   - Daily attendance submission
   - Status tracking and history
   - Mismatch resolution
   - Profile management

3. **`manager_documentation.html`** - 👔 **Manager User Guide**
   - Team management dashboard
   - Approval workflows
   - AI insights and predictions
   - Bulk operations

4. **`admin_documentation.html`** - 🛡️ **Administrator Guide**
   - System configuration
   - User and role management
   - Security settings
   - Backup and recovery

5. **`NOTIFICATION_SYSTEM_GUIDE.html`** - 🔔 **Notifications Guide**
   - Email, SMS, and Teams integration via Power Automate
   - Excel-based notification workflows
   - Recurrent notification triggers and custom alert configurations

6. **`system_architecture_documentation.html`** - 🏗️ **System Architecture**
   - Technical system design
   - Database schemas
   - API documentation
   - Integration patterns

## 🚀 Getting Started

### Option 1: Start with the Hub
1. Open `index.html` in your web browser
2. Browse the available documentation cards
3. Click on your role to get started
4. Use the Quick Start buttons for direct access

### Option 2: Direct Access
- **Vendors**: Open `vendor_documentation.html`
- **Managers**: Open `manager_documentation.html`
