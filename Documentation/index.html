User Roles & Responsibilities

Vendors
Submit daily attendance status, track work hours, manage personal records, and receive notifications about status changes.
Managers
Oversee team attendance, approve/reject submissions, access AI insights, generate reports, and manage team operations.
Administrators
Full system control, user management, system configuration, data imports, holiday management, and system monitoring.

System Data Flow

1
Vendor Status Submission
Vendors log in and submit daily attendance status with location and comments
2
Real-time Processing
System validates data, updates database, and triggers Excel file updates
3
Power Automate Integration
Excel changes trigger Power Automate workflows for notifications
4
Manager Review & Approval
Managers receive notifications and can approve/reject submissions
5
Reconciliation & Reporting
System compares with swipe data, detects mismatches, and generates reports
